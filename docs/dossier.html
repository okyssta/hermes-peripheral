Peripheral — a memory of what you've seen on screen

Hermes Agent Plugin Hackathon entry · dossier for verification · 5 Nov 2026 · okyssta/hermes-peripheral v1.0.1

1. The entry in one paragraph

Hermes can read a file you hand it and can look at the screen now. It cannot answer for a screen that is already gone — “that error I got yesterday”, “the price on that page”, “what was on screen when it broke”. Peripheral indexes the screenshots the OS already writes, reads them locally with Tesseract, and gives the agent four tools: screen_recall, screen_timeline, screen_show, screen_index — plus a /peripheral command and a bundled skill. The timeline puts the user's screens and the agent's own tool calls on one clock. Local only: no network calls, no capture daemon, secrets redacted at ingest — in the OCR text and in the agent-event log alike. /peripheral forget deletes the row and the thumbnail this plugin wrote for it; your screenshots are never touched.

3. What was built

Surfaces

  • 4 tools (toolset peripheral), 1 slash command, 1 observer hook (post_tool_call), 1 skill
  • Settings in plugin.yaml render in Desktop → Settings → Plugins
  • State in <HERMES_HOME>/plugin-data/peripheral/ via the documented storage API

Mechanics

  • Incremental scan by mtime+size+SHA-256; near-duplicates dropped at Hamming ≤ 3 on a 64-bit dHash
  • Tesseract as one bounded subprocess (25 s cap, one thread); no OCR ⇒ visual index instead of failure
  • SQLite FTS5 (porter) + BM25, re-ranked by recency and text richness; query sanitised into quoted prefix terms
  • Evidence snippet re-chosen from the stored text — the line with the most query terms, windowed around them
  • Redaction: sk-/ghp_/AKIA/AIza/Slack, JWT, bearer/basic, password:, credentials in connection URLs, private keys, card numbers, 32+ hex — applied to OCR text and to stored agent-event details

Measured on this machine (2 vCPU ARM, no GPU)

text stored            →  12,616 chars
warm rescan            →  0 images re-read

Privacy posture

  • Zero network calls; no telemetry, no sync, no model call to index
  • Never captures the screen — reads files the OS already wrote
  • /peripheral forget <id>|all deletes the row and the thumbnail this plugin wrote; pause; retention_days
  • The screenshots themselves are never modified or deleted — only copies the plugin made

The delta is one mechanism: a persistent, time-indexed percept of the user's screen that the agent can query, joined to a log of what the agent itself did. Scope of the claim: “no catalog entry and no repo in the wave does this”, not “no software anywhere does this”.

6. Review round 1 — what changed, and the test that holds it

An internal review read the code cold and reproduced three defects. Each is fixed in 25342ff, with a test that fails on the old behaviour. Nothing else in the submission changed its claim status.

DefectFix
/peripheral forget deleted rows but left the 360 px copy of the screen on disk. db.forget unlinks the thumbnail it wrote and sweeps the thumbs tree on forget all. Reproduced live: 10 thumbs / 41,692 bytes → 0, user's originals untouched.
Tests: test_forget_deletes_the_thumbnail_it_wrote, test_forget_all_sweeps_every_thumbnail.
Agent event details were stored verbatim, so --password= and bearer tokens reached the events table. Redaction moved to the storage boundary (db.record_event) and applied in the hook before truncation; a pattern for credentials inside connection URLs was added.
Tests: test_agent_event_details_are_redacted_before_storage, test_post_tool_call_hook_redacts_before_the_event_is_written.
The “model chose the tools” claim cited a script that sent the literal Bearer ***, and the video's answer text was hardcoded. The script uses the key, writes docs/demo-transcript.json / .txt, and the video renders its Q&A scene from that transcript; it refuses to render without one. The Q&A in §2 is the captured run.
Evidence: the transcript itself.

Minor items also fixed: before <time> was searched as a lower bound (now an upper bound, with a test), and the settings docstring pointed at a test file that did not exist.
